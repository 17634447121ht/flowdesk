# FlowDesk · Windows 流量浮窗

FlowDesk 是一个轻量的 Windows 桌面悬浮小组件，用来查看实时上传/下载速度、今日用量和当前账期用量。它从第一次运行开始记录，不会猜测应用启动前的流量。

## 使用

先按下方说明从源码编译，再双击生成的 `FlowDesk.exe`。浮窗默认置顶并显示在屏幕右上方，拖动右下角可以自由调整大小，尺寸会记住；点击标题栏的 `−` 会切换为只保留上下行速度和今日用量的紧凑模式，点击 `+` 恢复。关闭窗口会退出程序；右键托盘图标可以完全收起浮窗，统计仍会继续。

浮窗底部的“更新套餐”可以快速修改每月额度和结算日；更新套餐不会删除历史记录，本账期已经使用的流量默认保留。右键托盘图标可以打开设置和历史记录：

- 自动模式只统计已连接的物理以太网/Wi-Fi 网卡，会过滤常见 VPN、隧道、VMware、Mihomo、Docker 和抓包过滤器接口。
- 也可以在设置里明确选择一张网卡；如果它不存在或未连接，程序会停在安全状态，不会悄悄切换到另一张网卡。
- 额度使用十进制 GB（1 GB = 1,000,000,000 字节），在 80% 和 100% 时各提醒一次。结算日可设为 1–31，短月份按当月最后一天处理。
- 历史记录保存在 `%LOCALAPPDATA%\FlowDesk\usage.xml`，可以在历史页导出 CSV。统计包含局域网流量，可能和运营商账单存在差异。

## 从源码重新编译

在 Windows PowerShell 中进入本目录执行：

```powershell
.\build.ps1
```

编译只使用 Windows 自带的 .NET Framework 4.x C# 编译器和 WPF，不需要安装 SDK、NuGet 或管理员权限。`FlowDesk.exe` 会生成在本目录。

仓库只包含源码、图标、运行配置和编译脚本。编译产物与个人流量记录不会提交到仓库。
