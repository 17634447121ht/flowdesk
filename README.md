# FlowDesk

轻量的 Windows 网速与流量用量工具。查看实时上传／下载速度、今日和本账期用量，以及具体哪些程序在消耗流量。

**当前版本：1.3.1** · Windows 10 / 11 x64 · .NET Framework 4.8 · WPF

[下载最新版本](https://github.com/17634447121ht/flowdesk/releases/latest) · [更新记录](更新说明.md) · [验证范围](docs/VALIDATION.md)

## 下载与使用

在 [Releases](https://github.com/17634447121ht/flowdesk/releases) 下载发布压缩包，解压后双击 `FlowDesk.exe`。程序与 `FlowDesk.exe.config` 保持在同一目录。

新配置默认使用极简模式；从旧版更新会保留原先的显示选择。右键托盘图标 → **显示模式**，或打开设置切换：

| 模式 | 显示方式 | 适合的使用习惯 |
| --- | --- | --- |
| 超简模式 | 任务栏通知区域的两个数字图标 | 尽量少占桌面空间 |
| 极简模式 | 全透明双行悬浮网速窗 | 常看网速，希望文字更清楚 |
| 详细模式 | 完整用量浮窗 | 同时查看速度、套餐和累计用量 |

青绿色表示下载，紫色表示上传。极简与详细模式保留一个普通托盘图标，用于查看详情、切换模式、设置和退出；超简模式显示两个网速图标。

Windows 可能将图标放入隐藏图标区（`^`）。可将其拖到任务栏可见区域；图标排列由 Windows 管理。

## 极简模式

- 背景完全透明，无边框、标题、箭头或按钮；上方下载，下方上传。
- 使用 Windows 系统字体，固定 **12px**，接近任务栏日期大小。预留区域为 112×40，数字右对齐，不随速度变化缩放。
- 显示 `80K`、`0.12M` 等速度；`K`、`M` 分别表示 KB/s、MB/s，不受托盘三字符限制。
- 约每 3 秒显示这段时间的平均速度；悬停查看方向和精确值。网卡不可用时立即显示 `—`，空闲显示 `0`。

按住可见数字拖动可以移动位置，位置与详细浮窗分别记忆。右键数字或托盘图标 → **极简浮窗选项**，可设置：

| 选项 | 行为 |
| --- | --- |
| 锁定位置 | 禁止拖动，仍可右键打开菜单 |
| 鼠标穿透 | 连数字也不拦截鼠标，直接操作下方桌面；从托盘菜单取消 |
| 文字颜色 | 浅色、深色或跟随系统主题 |
| 文字淡阴影 | 仅为文字增加轻微阴影，背景保持透明 |
| 重置浮窗位置 | 将浮窗放回可见工作区 |

全透明空白区域会自然让鼠标穿过，拖动时请按住数字。自动文字颜色跟随系统主题，不分析壁纸；对比不足时可手动选择深浅文字。

## 超简与详细模式

超简模式使用 Windows 原生通知区域图标，最多显示三个字符，例如 `80K`、`.1M`、`13M`。`.1M` 约为 100 KB/s；小于 1 KB/s 的非零速度显示 `<1K`。约 3 秒平均刷新，悬停查看精确值。点击图标会在任务栏附近展开详情，点击其他地方或按 Esc 收起。

详细模式保留完整面板：

- **更新套餐**：设置月度额度和结算日，达到 80% / 100% 时提醒。结算日可选 1–31，短月份按最后一天处理。
- **用量记录**：查看每日上下行和趋势；每 5 秒自动刷新，也可手动刷新、导出 CSV。
- **谁在用网**：查看程序名、PID、实时上下行、今日和本账期用量；支持搜索与排序。

详细浮窗可拖动标题栏移动、拖动右下角调整尺寸；`−` 切换紧凑视图，`+` 恢复。

## 程序流量与统计范围

**普通权限可以统计网卡总量；新采集程序明细需要管理员权限。** 在“谁在用网”中点击“以管理员身份启用”，确认 Windows 提示后，程序会保存并以管理员权限重新打开。取消提示会继续普通模式，已有程序历史仍可查看。

登录 Windows 自动启动使用普通权限；重启后如需程序级采集，请再次启用或以管理员身份打开程序。

- 网卡总量优先根据 Windows 硬件接口属性选择已连接的物理网卡，也可手动指定网卡。手选网卡断开或不存在时会显示异常。
- 程序明细通过 Windows ETW 统计所有网卡的 TCP/UDP、IPv4/IPv6 发送接收事件，包括局域网及可能出现的本机通信。
- 程序事件和物理网卡计数的范围不同，程序明细的合计不要求与网卡总量一致。VPN／代理转发可能计在代理程序上；无法识别的程序和事件丢失会明确提示。
- 只累计运行／启用采集后的流量，不能补记退出期间的用量，也不能把旧网卡总量追溯到具体程序。
- 按十进制计量：1 GB = 1,000,000,000 字节。程序明细保留最近约 400 天，记录容量超限后新程序流量归入“其他程序”。

程序级真实采集的验证限制见 [验证记录](docs/VALIDATION.md)。

## 更新与数据

先从托盘选择 **退出并保存**，再将新版程序与配置文件放回原目录。个人记录独立保存在 `%LOCALAPPDATA%\FlowDesk`：

| 文件 | 内容 |
| --- | --- |
| `usage.xml` | 网卡每日用量、套餐与显示设置 |
| `process-usage.xml` | 程序每日用量 |
| `.bak` | 上次保存备份 |

保存采用后台串行写入和临时文件原子替换，失败后重试，退出时等待最后一次保存。损坏文件会尝试从备份恢复，并保留 `.damaged-*` / `.recovered-*` 副本。请勿在运行中手动编辑统计文件。

如果移动了程序目录，到设置中保存一次开机启动选项，以更新启动路径。更新程序本身不会删除独立数据目录。

## 从源码构建

在 Windows、.NET Framework 4.8 环境中运行，无须安装 .NET SDK 或 NuGet：

```powershell
.\build.ps1 -OutputDirectory .\bin\release
```

直接运行 `build.ps1` 会更新仓库目录内的程序，并保留 `FlowDesk.exe.previous`。若程序正在使用，先从托盘退出再构建。

源码主要分为：`src/Core.cs`（网卡统计和持久化）、`src/ProcessTraffic.cs`（程序流量）、`src/Main.cs`（模式与主面板）、`src/MinimalSpeedWindow.cs`（透明网速窗）、`src/Dialogs.cs`（设置与明细）。
